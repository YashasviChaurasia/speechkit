# SpeechLens Intelligence Positioning Design

## Goal

Improve the standalone demo's first impression with frontend copy that positions SpeechLens as a speech-intelligence layer for an Agentic Video Editor.

## Scope

- Replace the hero marker, heading, and description.
- Add one compact benefit line below the hero.
- Explain speaker-aware search, precise playback evidence, and the editor-plugin role.
- Do not add API calls, controls, backend routes, or data changes.

## Placement

The message stays in the existing hero, before provider configuration and upload. It gives the demo context without competing with the analysis workflow below.

## Verification

The static UI test asserts the new positioning text and the benefit-line target. Existing UI tests confirm the current page structure remains intact.
